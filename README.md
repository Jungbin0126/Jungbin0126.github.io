# Jungbin Yoon — portfolio

Plain HTML + CSS, no build step. Open index.html in a browser to preview.

- Research PDFs: papers/research-1.pdf, research-2.pdf, research-3.pdf
- Drawings: images/drawings/
- Edit text directly in each .html file; shared styles are in style.css.

## Host on GitHub Pages
1. Create a repo named `Jungbin0126.github.io`.
2. Upload everything in this folder to the repo root.
3. Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
4. The site goes live at https://jungbin0126.github.io
